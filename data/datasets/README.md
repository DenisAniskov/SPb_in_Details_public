# Пилотные наборы данных

Два набора используются публичным backend'ом при расчёте оценок по
существующей прогулке. Ни один из них не строит и не выбирает маршрут.

## `shade_buildings_spb_pilot.sqlite`

| Поле | Значение |
| --- | --- |
| Назначение | Модель затенённости: контуры и высоты зданий Санкт-Петербурга |
| Источник | OpenStreetMap (контуры зданий и теги высоты) |
| Лицензия | **ODbL 1.0**, © OpenStreetMap contributors |
| Снимок источника | `../provenance/phase_c7_2/centre_palace.osm.xml.gz` (выгрузка Overpass) и `../provenance/phase_c7_2/centre_palace.overpassql` (сам запрос) |
| Журнал acquisition | `../provenance/phase_c7_1/requests.json`, `../provenance/phase_c7_1/manifest.json`, `../provenance/phase_c7_2/manifest.json` |
| Покрытие | `../provenance/phase_c7_1/coverage_audit.json` — доля зданий с известной высотой и принятое по умолчанию значение там, где высота не указана |

Ограничение: высоты зданий в OSM неполны. Там, где высота не указана,
используется явно задокументированное значение по умолчанию, поэтому оценка
тени — модель, а не измерение.

## `puddle_ways_spb_pilot.json`

| Поле | Значение |
| --- | --- |
| Назначение | Относительная оценка склонности поверхности к лужам вдоль прогулки |
| Источник | OpenStreetMap (типы дорожных путей и их покрытие) |
| Лицензия | **ODbL 1.0**, © OpenStreetMap contributors |
| Модельные осадки | Open-Meteo (модель DWD ICON); пробы сохранены в `../provenance/phase_c7_2/weather_probe.json` и `weather_public_pilot.json` |
| Манифест | `../provenance/phase_c7_2/manifest.json` |

Ограничение: набор описывает поверхность и модельные осадки. Он не является
наблюдением за водой, не учитывает локальный дренаж и не выдаёт глубину или
безопасность прохода.

## Атрибуция

- В интерфейсе приложения: «Места: © OpenStreetMap contributors • Карты: Яндекс»
  со ссылками на копирайт OSM, текст ODbL 1.0 и условия Яндекс.Карт.
- Для данных Open-Meteo: «Weather data by Open-Meteo.com; DWD ICON model».

При распространении копий наборов сохраняйте уведомление ODbL и ссылку на
копирайт OSM. Данные Яндекса в эти наборы не добавляются: их лицензия
несовместима с ODbL.
